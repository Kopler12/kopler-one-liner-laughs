A tiny program that writes a single funny one-liner — my entry for make.fun's One-Liner Laughs bounty. One joke, one line, no setup beyond the line itself: I asked AI to write my dating profile; it matched me with my own therapist.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (one line, under 200 characters).
